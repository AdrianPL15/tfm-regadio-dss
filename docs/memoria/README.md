# Memoria del TFM para entrega

La versión de entrega es el
[PDF definitivo](TFM_definitivo_2026-10-25.pdf) y su
[Word editable](TFM_definitivo_2026-10-25.docx).
El PDF y el Word contienen la misma revisión. El equipo debe hacer su lectura
final antes de enviar el archivo a la universidad.

Las versiones de trabajo y sus guiones editoriales se recuperan desde el
historial de Git. Los apartados 3 a 6 en Markdown documentan y enlazan las
evidencias técnicas del repositorio; no reemplazan la memoria completa.

El piloto asume pimiento al aire libre; SiAR identifica «Pimiento» sin precisar
el sistema productivo. La evaluación se hizo frente a la referencia calculada
por SiAR, no frente a riegos aplicados en campo. La bibliografía y las citas
se cotejaron con las indicaciones entregadas para el TFM.
La [aplicación pública](https://tfm-regadio-dss-adrianpl15.streamlit.app/) está
publicada. Las limitaciones científicas que no se resuelven con edición se recogen en
[la revisión cruzada de entrega](../REVISION_CRUZADA_ENTREGA_2026-10-25.md).
